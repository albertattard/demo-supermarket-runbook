# AI-Assisted Issue Workflows

Assess an issue before implementation:

```text
Use $review-issue-readiness for <issue-url>.
```

Implement one ready issue:

```text
Use $implement-issue for <issue-url>.
```

Create isolated primary and alternative candidates:

```text
Use $orchestrate-issue-implementations for <issue-url>.
```

Independently review one prepared candidate worktree:

```text
Use $review-implementation to review <issue-url> in the supplied candidate worktree against its recorded baseline and evidence matrix.
```
